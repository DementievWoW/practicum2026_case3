## Что это
GSQLi — метод мутации SQLi-payload'ов на базе Generative Adversarial Network для обхода Web Application Firewall и SQLi-детекторов. Применяет серию мутаций к оригинальным payload, делая их трудно различимыми для классификаторов как malicious, при сохранении семантической эквивалентности атаки. Сосредоточен на adversarial evaluation WAF, чтобы выявить их слабости.

## Почему релевантно
Эталон adversarial-генерации SQLi payload против защит — критично для построения benchmark уязвимостей для LLM-судьи PostgreSQL. Мутационные образцы из GAN можно использовать как test-suite ("can the judge detect these?") и для измерения robustness судьи к замаскированным SQLi.

## Цитаты (по WebSearch / DBLP confirm)
- "GSQLi is a novel method to mutate payload for SQL Injection (SQLi) attacks to deceive WAFs or detectors."
- "By leveraging the Generative Adversarial Network (GAN), SQLi payloads are generated by applying several mutations on the original ones, making it challenging for detectors to identify them as malicious."
